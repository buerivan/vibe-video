# 配音对接说明

## 方式 A（推荐）：engine/tts.py 自动配音

`engine/tts.py` 用晓晓音色（zh-CN-XiaoxiaoNeural）为每镜生成语音，并把真实语音时长写回
`config.json` 的 `shot.dur`，画面/字幕/合成全部反向对齐，**无人工长气口**。详见 `SKILL.md` 阶段 5。

```bash
python engine/tts.py --config scenes/<选题>/config.json
# ⚠️ 不要给 encode 加 --sub：画面里已烧入 HUD 字幕，再加 SRT 会双层字幕
node engine/encode.js --frames output/<选题> --audio output/<选题>/voice/voice.mp3 --out output/<选题>.mp4
```

- 优点：节奏由声音决定，稳定、可复现、跨平台一致
- 限制：国内需代理（默认 Clash `http://127.0.0.1:7897`）；edge-tts 音色有限（晓晓/云扬等神经网络音色）

## 方式 B（旧 / 无代理时）：剪映文本朗读

agent 交付**无声 MP4 + SRT**，配音在剪映完成。这份文档记录标准动作。

> ✅ **已实测**（2026-10-14，许鹏用剪映跑通「反驳型人格」第一条）：导入 SRT → 文本朗读 → 得到配音 → 删掉字幕轨，全流程可行。
> 关键点：**成片里已经烧进了字幕**（字幕是渲染的一部分），所以朗读完必须删掉/隐藏剪映的字幕轨，否则叠成双层。删字幕轨不影响已生成的朗读音频。

## 标准流程

1. 剪映 → 导入 `output/<选题>.mp4`（无声画面）
2. 文本 → 导入本地字幕 → 选 `output/<选题>.srt`
3. 全选字幕条 → **朗读** → 选一个音色（知识类推荐沉稳男声/女声，语速 1.0x）
4. 播放检查：若某条字幕的语音长于字幕显示时长，语音会溢出到下一条
   - 轻微溢出：接受（自然停顿）
   - 明显溢出：见下方"二程对齐"
5. 配乐（音量 -20dB 左右，别压人声）→ 导出

## 二程对齐（帧级卡点要求时）

画面是按旁白字数**估算**的（260 字/分钟）。如果实际朗读后某镜明显偏松/偏紧：

1. 在剪映里读出该镜的**实际起始秒数**
2. 把新时长写回 `scenes/<选题>/config.json` 对应 shot 的 `dur`
3. 只重渲受影响镜头：
   ```bash
   node engine/shoot.js --from <镜起始秒> --dur <新时长> --fps 30 --out output/<选题>_fix
   ```
4. 用 `engine/encode.js` 把修正帧替换进去重新合成

> 一般情况一程即可，不需要二程。

## 字幕生成

```bash
node engine/mksrt.js --config scenes/<选题>/config.json --out output/<选题>.srt
```

一镜一条字幕，长句自动按每行 ~18 字拆行。

## 发布物料

- **标题**：提问式优先（"为什么有人习惯性反驳别人？"），不用断言式
- **封面**：从成片选一帧导 3:4 竖版，压一句钩子文字
- **标签**：`#vibe知识大赏` 固定 + 2-3 个与内容强相关的标签
  （不要乱挂热门活动标签，会歪账号标签）
- **置顶评论**：发布后 30 分钟内发一条引导互动的话，回前 10 条评论
- **合集**：系列内容必须进合集，这是系列导流主入口
