# 设计规范 v2 · 浅色轻松版（待许鹏审定）

> 2026-10-14。学习 bruno-simon.com / recent.design / threejs.org 后得出。
> 背景：v1 深褐金 + 暗角 + Bloom + 金属材质，走"压抑/电影感"路线，与"轻松"需求相反，**推翻**。

## 一、三站学到的关键结论

**bruno-simon.com（最大启发）**
- 轻松感的第一来源**不是颜色浅，是"玩具感"**：圆润形体、明亮纯色、可交互（开车/跳/喇叭/搬东西）
- **物理弹跳**：重力、跳跃、碰撞——画面"活"的根源
- **容错设计**：卡住有 "I'm stuck" 传送、Respawn 重置——不惩罚用户
- 世界配色＝**蓝天绿地 + 高饱和物体**（红车、白排球），不是"高级灰"

**recent.design（趋势）**
- 大字排版（oversized typography）
- **Blob 有机形态**（圆润不规则形，替代尖角）
- Motion studies：把微动效当研究对象，动效本身是内容
- 品牌化 UI 组件：一套可复用组件语言

**threejs.org**
- 官方示例大量用**浅色背景**，专业感和清晰度反而更高
- 极简＝大量留白 + 清晰层级

## 二、对许鹏建议的裁定（采纳 / 修正 / 推翻）

| 许鹏的建议 | 裁定 | 理由 |
|---|---|---|
| 浅色调 | **修正** | 浅色 ≠ 纯白+纯黑（那正是"廉价感"来源）。用**暖白底 #FAF7F1 + 深暖灰字 #26231F**，带温度的浅 |
| 线条更粗 | **采纳** | 但线色要用主色系/中深色，**不用纯黑**（浅底上粗黑线=压抑+廉价） |
| 4/8px 网格 | **采纳** | 3D 里换算为世界单位等距（0.25 世界 ≈ 8px 视觉等价 @1080p） |
| 限定调色板 | **采纳** | 铁律，见下 |
| 加 transition/animation | **采纳并加强** | 关键是**弹性曲线**（easeOutBack/spring，有过冲）而非线性过渡——"轻松感"的物理来源 |
| 系统字体栈 | **采纳** | 中文 PingFang SC / MiSans / 思源黑体；字重分级 700/500/400 |
| 阴影、圆角、留白 | **采纳** | **浅色设计的层次全靠阴影**（不能用暗角）。3D 里换成"接触阴影+环境光+色相层次" |
| —— | **新增（推翻我自己）** | **Bloom 在浅色下是毒药**：白底会被 bloom 推成灰块。浅色版停用或极弱（strength ≤0.12） |
| —— | **新增** | 材质改**哑光**：roughness 0.65-0.8、metalness 0。金属冷硬感与"轻松"相斥 |

## 三、调色板（限定 6 色，一色一义）

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg` | `#FAF7F1` | 奶油白底（暖，不冷） |
| `bgSoft` | `#F0EAE0` | 卡片/面板次背景 |
| `ink` | `#26231F` | 主文字/主体（对比度 13:1，不用中灰，避免糊） |
| `inkSoft` | `#6E675C` | 次要文字/注释 |
| `accent` | `#FF6B4A` | 珊瑚橙——唯一强调色（结论/当前项/焦点） |
| `accent2` | `#2E8B77` | 松石绿——第二语义（正面/答案/对照组） |
| `orbit` | `#C9BCA8` | 结构线（**粗线**，3-5px 等价） |

## 四、版式与间距

- **间距**：8 的倍数（8/16/24/32/48/64）；3D 世界单位 0.25 一级
- **圆角**：DOM 16-24px；3D 用胶囊体/圆角柱替代尖角几何体
- **字号层级**：主标题 700 / 副标题 500 / 正文 400 / 注释 300，比例约 1.5:1.25:1:0.85
- **字距**：中文标题 letter-spacing 0.06-0.12em，正文 0.02em
- **留白**：画面四周至少留 12% 边距，元素不贴边

## 五、光影（浅色下的层次三件套）

浅色没有暗角可用，层次靠：
1. **柔和半球环境光**：`HemisphereLight(#FFFFFF, #E8DFD2, 1.1)`，模拟天光
2. **接触阴影**：物体下方一张 radial-gradient 贴图的圆盘，opacity 0.18-0.25（比 v1 的 0.10 明显，但不抢）
3. **色相层次**：同类元素用 accent/accent2 区分，而非用明暗区分

方向光改为弱侧光（强度 0.6-0.8）只做"定性"，不做强对比。

## 六、动效原则

- **入场**：scale 0.88 → 1.04 → 1（回弹）+ opacity 0→1，时长 0.35s，easeOutBack
- **推进**：保留相机缓推，但**幅度减半**、easeInOut（浅色下大推进易晕）
- **切换**：镜间交叉溶解 0.3s（替代硬切）
- **常驻**：所有物体带极轻微浮动（±0.06 世界单位，2-3s 周期）——"呼吸感"
- **禁止**：线性过渡、生硬跳变、闪烁

## 七、与 v1 的差异清单（改一处列一处）

| 项 | v1（深色压抑） | v2（浅色轻松） |
|---|---|---|
| 背景 | #241C14 径向渐变压暗 | #FAF7F1 径向渐变提亮 |
| Bloom | strength 0.26 | **停用**（或 ≤0.12） |
| 暗角 | 有 | **移除** |
| 材质 | Standard + metalness 0.45 | Standard/Physical + **metalness 0, roughness 0.7** |
| 灯光 | 主光 0.85 + 边缘光 1.15 + 环境 0.28 | **半球主光 1.1 + 弱侧光 0.65**（去掉边缘光） |
| 线条 | 细、暗色 orbit | **粗、中深色**，round cap |
| 几何体 | 尖角（Box/Torus/Cone） | **圆角/胶囊体**优先 |
| 相机推进 | z 16→11.5 | 幅度减半 + easeInOut |
| 切换 | 硬切 | 交叉溶解 0.3s |
| 接触阴影 | opacity 0.10 | opacity 0.22（更明显） |

同一镜头（object-3d 镜 2 + branch-tree 镜 6）按 v2 重做，出 2 段 6-8 秒对比片给许鹏看，确认后再推全片。

## 九、实现状态（2026-10-14 · 已出对比片）

**产物**：`output/compare_v1v2.mp4`（1920×1080·13s·左 v1 深色 / 右 v2 浅色，带标签）；单幅 `output/look_a2.mp4`（v1）、`output/look_b.mp4`（v2）。测试场景 `scenes/v1-compare` / `scenes/v2-compare`（同内容仅主题不同）。

**引擎改动**（深色路径原样保留，v1 场景不受影响）：
- `scene.js` 由 `theme.mode: "light"` 驱动：背景径向**提亮**（中心 +4% / 边缘 ×0.965，无暗角）、**停用 Bloom**、半球柔光 1.05 + 弱侧光 0.55 + 正面补光 0.25（去边缘光）、隐藏 `#vignette`、字幕换深色黑体 + 软阴影。

**组件改动**：
- `object-3d` / `branch-tree`：浅色下材质哑光（metalness 0 / roughness 0.7）、去加性辉光、接触阴影（`shadowTexture`，opacity 0.22）替代彩色环/呼吸光晕。
- `branch-tree` 浅色边线用 **`growTube` 粗管**（WebGL 的 LineBasicMaterial 忽略 linewidth，vendor 无 fat-line 插件；圆柱管实体几何实现，圆头随生长端出现，接口同 `growLine`）。结论路径管径 0.09 / 结构线 0.07。

**新工具**（`components/_lib/sprites.js`）：`shadowTexture()` 接触阴影纹理、`growTube()` 可生长粗管、`textSprite` 新增 `bold` 选项。

**全组件适配状态（截至 2026-10-14）**：
- 已浅色适配：`object-3d`、`branch-tree`（试点对比片）、`big-text`、`split-compare`、`timeline`（晕轮效应首片 64s 验证通过）。均落实两条规则——
  1. `textSprite` 一律传 `shadow: false, bold: true`（深色投影在浅底糊成灰团、sans 细字在浅底发灰）；
  2. 强调色小字改用「accent 混 ink 35%」的深色变体（#FF6B4A 在奶油底对比度仅约 2.5:1），形状/线条仍用原 accent。
- 仍待适配：`particles`（仅氛围粒子，暂未用于真片；届时同样按上述两条规则处理）。
