# 七阶段工作流（详版）

对应 `SKILL.md` 的操作手册。每阶段有明确产物，不合格回滚到对应阶段。

## 1. 选题立项

**产物**：`scenes/<选题>/storyboard.md` 开头几行

- 一句话命题
- 四问检验：为什么看 / 为什么赞 / 为什么论 / 为什么转
- 红线预筛：
  - 不做"你是哪种人"测试式引流（天然引战）
  - 不贴病理标签（如把某类人说得像病症）
  - 不点名批评具体个人/账号
  - 不做政治化表述、不用真人肖像、不出现地图
- 判断标准：四问全过才立项；3 个不过就换题

## 2. 考据成稿

**产物**：`facts.md`（事实清单）+ 旁白稿（400–500 字）

- 每条事实一行，标注出处：`书名/篇名/URL/文件路径`
- 单独列"禁改清单"：数字、年代、人名、术语、书名——AI 不得改写
- 旁白按 260 字/分钟估算，一镜 1–2 句
- 结尾留一句金句（情绪落点）

## 3. 分镜脚本

**产物**：`shots.md`

| # | 时长 | 旁白 | 画面母题 | 组件 | 卡点 |
|---|------|------|----------|------|------|
| 1 | 6s | 一个符号，两个主人。 | 3D 器物旋转 | object-3d | 落重音 |

- 每镜时长 = 旁白字数 / 260 × 60 + 0.4s
- 8–12 镜；一镜只说一件事
- 组件选型见 SKILL.md 的速查表

## 4. 场景装配

**产物**：`config.json`

- `theme` 从 `themes/` 整份拷入（一色一义，≤5 色）
- 每镜：`{ component, dur, caption, config }`
- 3D 特写必须给 `shot.camera`，否则默认相机（z=26）太远
- 坐标安全区：x ∈ [-5, 5]，y ∈ [-9, 9]；**超出即出血**
- config.json 保持纯 JSON

## 5. 渲染合成

```bash
node engine/serve.js --root scenes/<选题>        # 终端 A
node engine/shoot.js --out output/<选题>          # 终端 B
node engine/mksrt.js --config scenes/<选题>/config.json --out output/<选题>.srt
node engine/encode.js --frames output/<选题> --out output/<选题>.mp4
```

分段调试：`--from <秒> --dur <秒> --fps 15`

## 6. 质检（三道闸）

```bash
node engine/qc/inspect.js output/<选题>          # 像素统计 + 构图
node engine/qc/ascii.js output/<选题>/frame_000NN.png 100
```

1. **像素闸**：`有内容=true`、`在运动=true`、无"贴边/出血/偏窄/偏矮"提示
2. **事实闸**：旁白逐字对 `facts.md`；禁改清单一个不动
3. **人审闸**：抽帧终审（新流程先跑两条再定抽检规则）

常见构图问题与修法：
| 现象 | 原因 | 修法 |
|---|---|---|
| 水平贴边/出血 | 主体宽超过竖屏可见宽（约 10.7 世界） | 收窄组件 / 拉远相机 |
| 主体偏窄 | 竖屏宽度浪费 | 放大主体或改用竖向构图 |
| 整屏发灰 | 加性混合辉光 scale 过大 | 把 halo scale 压到 ≤ 4.5 |
| 粒子不显示 | position 含 NaN（对象被视锥剔除） | 检查目标点是否三分量齐全 |
| 文字太小 | textSprite 的 px 与画布高度不匹配 | 别传 px，让它按 H×0.6 自动定 |
